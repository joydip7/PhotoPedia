# PhotoPedia
This project is a beginner–friendly Sliding Sidebar Navigation Menu UI, built using only HTML and CSS — no JavaScript.
The main purpose of this mini–project was to learn how a sidebar works, how it slides inside/outside the screen, and how the toggle button can be controlled using just a checkbox selector in CSS.

This project helped me strengthen my fundamentals in layout design, positioning, hover effects, transitions, and UI logic using pure CSS.
